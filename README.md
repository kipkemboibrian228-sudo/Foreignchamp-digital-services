# Foreign Champ Digital Services

Responsive static website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive premium navy/blue styling
- `script.js` — mobile navigation, year, WhatsApp link

## Before publishing
1. Open `script.js`.
2. Replace `2547XXXXXXXX` with your Kenyan WhatsApp number in international format (254 followed by 9 digits; no plus sign or spaces).
3. Replace portfolio concept tiles with genuine project screenshots and real demo URLs where available.
4. Review the price scope and contact details.

## Deploy with GitHub + Vercel
1. Create a GitHub repository named `foreign-champ-digital-services`.
2. Upload the three website files and this README to the repository root.
3. Sign in at https://vercel.com and choose Add New → Project.
4. Import the GitHub repository.
5. For a static HTML site, leave framework preset as Other; leave build command and output directory blank unless Vercel requests otherwise.
6. Select Deploy. After deployment completes, open the generated `.vercel.app` URL and test mobile navigation and WhatsApp CTA.
7. Future commits to the connected Git repository trigger new deployments.

## Android-only route
Use GitHub in Chrome with Desktop site enabled, create the repository, and upload the files through Add file → Upload files. Then import that repository in Vercel as above.

## Notes
No backend, database, paid APIs, form collection, testimonials, or fabricated client results are included. The WhatsApp CTA is intentionally a placeholder until you configure your number.
